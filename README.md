# Election Night for Windows

Download **ElectionNight.exe** from the [latest release](https://github.com/noamvb/election-night-releases/releases/latest/download/ElectionNight.exe), put it in its own folder and double-click it. If Windows says "Windows protected your PC", click More info, then Run anyway.

Keep the black window open while you watch; your recorded results are saved in the `ElectionNight data` folder next to the exe. The app updates itself from this page each time it starts.
